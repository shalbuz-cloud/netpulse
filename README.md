# NetPulse

CLI-утилита для замера скорости скачивания (download). Выполняет 10 последовательных HTTP GET-запросов к указанному URL и выводит детальные метрики: латентность, пропускную способность и сводную статистику.

## Возможности

- **10 последовательных запросов** — каждый следующий начинается только после полного чтения тела предыдущего ответа
- **Без кэширования** — отправляет заголовки `Cache-Control: no-cache, no-store, must-revalidate` и `Pragma: no-cache`
- **Прогресс в реальном времени** — красивый прогресс-бар с текущей скоростью, ETA и статистикой по каждому запросу
- **Итоговая сводка** — общее время, средняя латентность, общий объём данных, средняя скорость
- **Двоичные единицы** — KiB/MiB/GiB для объёма, KiB/s/MiB/s для скорости (см. [Единицы измерения](#единицы-измерения))
- **Минимум зависимостей** — только `httpx` и `rich` (устанавливаются через `uv`)

## Требования

- Python **3.12+**
- `uv` (рекомендуется) или `pip`

## Установка

### С `uv` (рекомендуется)

```bash
# Клонируем репозиторий
git clone https://github.com/shalbuz-cloud/netpulse.git
cd netpulse

# Создаём виртуальное окружение и ставим в editable-режиме
uv venv
source .venv/bin/activate
uv pip install -e .
```

### С `pip`

```bash
git clone https://github.com/shalbuz-cloud/netpulse.git
cd netpulse
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Использование

```bash
netpulse <URL>
```

### Пример

```bash
# Тест на httpbin (1 MiB случайных данных)
netpulse https://httpbin.org/bytes/1048576
```

## Единицы измерения

| Величина | Единица | Определение |
|----------|---------|-------------|
| Объём данных | **KiB** (кибибайт) | 1 KiB = 1024 байта |
| Объём данных | **MiB** (мебибайт) | 1 MiB = 1024² = 1 048 576 байт |
| Объём данных | **GiB** (гибибайт) | 1 GiB = 1024³ байт |
| Скорость | **KiB/s**, **MiB/s**, **GiB/s** | Байт в секунду в двоичных единицах |

### Почему двоичные (IEC) единицы?

Сетевую пропускную способность принято указывать в **мегабитах в секунду (Мбит/с)**, а размер файлов — в **байтах**. Использование двоичных префиксов (KiB, MiB, GiB) устраняет расхождение 2.4% (KiB vs KB) — 7.4% (GiB vs GB) между десятичной и двоичной интерпретацией. Утилита выводит **MiB/s** (мебибайт в секунду). Для перевода в Мбит/с: умножьте на **8.3886** (так как 1 MiB/s = 8.3886 Мбит/с).

## Тестовые URL

| URL | Размер | Описание |
|-----|--------|----------|
| `https://httpbin.org/bytes/1048576` | 1 MiB | Случайные байты |
| `https://httpbin.org/bytes/10485760` | 10 MiB | Случайные байты |
| `https://speed.hetzner.de/100MB.bin` | 100 MB | Скоростной тест Hetzner |
| `https://proof.ovh.net/files/10Mb.dat` | 10 MB | Тестовый файл OVH |
| `https://proof.ovh.net/files/100Mb.dat` | 100 MB | Тестовый файл OVH |

> **Совет:** Для стабильных замеров на быстрых каналах используйте файлы 10–100 MiB.
